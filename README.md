#Informatyka_2026_27

Jako projekt zaliczeniowy wykonam symualcje lądowania statkiem kosmicznym na platformie. Gracz steruje ręczenie za pomocą klawiszy strzałek, lub "wsad". Ale jest możlwość włączenia lotu automatycznego, który wykorzystuje regulator PID.

Projekt zostanie napisany przeze mnie, bez użycia gotowych części kodu z modeli AI. Sztuczna inteligencja pomoże mi jedynie w zaplanowaniu struktury programu.
